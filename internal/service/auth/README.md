# AuthService

Сервис для работы с аутентификацией пользователей через JWT токены.

## Описание

AuthService предоставляет функциональность для генерации и проверки JWT токенов, используемых для аутентификации пользователей в системе. Сервис использует симметричную криптографию (HS512) для подписи токенов.

## Методы

### NewAuthService(secret string) *AuthService
Создает новый экземпляр AuthService с указанным секретом для подписи токенов.

### GenerateToken(userID string) (string, error)
Генерирует новый JWT токен для указанного пользователя. Токен действителен в течение 24 часов.

### ValidateToken(tokenString string) (*Claims, error)
Проверяет действительность JWT токена и возвращает Claims при успешной проверке.

### GenerateUserID() (string, error)
Генерирует новый уникальный идентификатор пользователя в формате UUID4.
